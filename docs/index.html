Features

Two-hit Deagle

50 HP a shot from 10 starting rounds — no reloads. Two hits and it's over.

Knife closer

35 HP in a fast 120° frontal swing, 2.1 m reach, no ammo. Finish what the Deagle started.

First to 5

Free-for-all in one arena. Five kills and a VICTORY overlay ends it.

Pickups

Ammo and health crates scattered across the map to fight over.

Healing zone

A pocket in the south that patches you back up — if you can hold it.

Speed pads

Boost tiles for escapes, chases and sudden flanks.

Run it locally

npm install
npm install --prefix client
npm install --prefix server
npm run dev
docker run -p 3001:3001 ghcr.io/salar-prog/knife-deagle-fight:latest

npm: server on :3001, client on :5173 — open two browser profiles to duel. Docker: single process on :3001.

Tech stack

LAYERTECH
RenderingThree.js — matcap-shaded low-poly arena
PhysicsCannon.js — shared client/server world, z-up
NetcodeSocket.IO — snapshot relay + combat events
BuildVite client, Node ≥ 18 server

Deploy

The Docker image serves the built client and the Socket.IO server from one Node process on :3001.

Self-hosting examples live in deploy/: a hardened systemd unit and an nginx proxy with WebSocket upgrade headers for /socket.io/.
