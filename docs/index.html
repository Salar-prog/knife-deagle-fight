KNIFE DEAGLE FIGHT

Two-hit Deagle. Swing first.

What is it?

A browser-based, real-time multiplayer on-foot arena duel: knife and Deagle, free-for-all in a dedicated 100×100 m skatepark-style arena. First to five kills wins. Built with Three.js, Cannon.js and Socket.IO. Forked from REDLINE by Victor Galvez (foundation: Bruno Simon's folio-2019).

Controls

ACTIONKEYS
MoveWASD / arrows
SprintShift
JumpSpace
AimMouse (pointer lock)
Fire / slashLMB (alias F)
Swap weapon1 2 Q wheel
ChatEnter

Run it

npm install
npm install --prefix client
npm install --prefix server
npm run dev

Server on :3001, client on :5173. Open two browser profiles to duel.

Docker

docker run -p 3001:3001 ghcr.io/salar-prog/knife-deagle-fight:latest
